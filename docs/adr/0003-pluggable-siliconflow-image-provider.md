# ADR 0003：生图走可插拔 provider，默认硅基流动双模型

- **日期**：2026-08-30
- **状态**：已接受
- **相关**：ADR 0004（成本护栏）

---

## 背景

上身图需要"图生图"能力：输入本人参考照 + 搭配描述，输出穿着效果。候选链路比价如下：

| 链路 | 单价 | 特点 |
|---|---|---|
| 云开发 AI+ 混元官方 | ¥0.5/张 | 免额外 key，但最贵 |
| 阿里云旧试穿模型（已终止） | ¥0.21/张 | 专为试穿优化，需阿里云 key |
| 通义万相 | ¥0.20/张 | 需阿里云 key |
| **硅基流动·图生图** | **约 ¥0.10/张** | 需硅基流动 key |
| **硅基流动·文生图** | **约 ¥0.036/张** | 最便宜，但**无参考照能力** |

按"每天只对中意的一套点一次"估算，混元官方月支出约 15 元，硅基流动约 1–3 元，**差 5 倍**。

另一个约束是**供应商不稳定**：SiliconFlow 会周期性上下架模型，模型名可能失效。若把模型名硬编码进业务逻辑，换模型就要改业务代码。

## 决策

1. **默认走硅基流动**，按有无参考照自动选模型：
   - **有参考照** → 图生图模型（Qwen-Image-Edit 系列）
   - **无参考照** → 纯文生图模型（Z-Image-Turbo），按身形参数生成模特图，效果弱一档但可用

2. **provider 可插拔**：生图实现封装成独立分支，靠一个配置项切换，业务代码零改动。已内置四套实现，备选链路随时可切。

3. 模型名、密钥、月额度**全部走云函数环境变量**，改链路不改代码。

### 关键坑（务必记住）

**Z-Image-Turbo 是纯文生图模型，传参考图会直接报错。**
早期版本误以为它支持图生图，导致首次调用失败。有参考照时必须用 Qwen-Image-Edit 系列。

另外，**Qwen-Image-Edit 系列不接受 `image_size` 参数**，传了会报错。代码已按分支分别构造请求体，改模型时不要顺手把这个参数加回去。

## 取舍

**放弃的**：

- 最省事的官方链路（混元免 key），代价是 5 倍成本
- 最贴合的专用试穿模型（已终止），代价是 2 倍成本
- 单一供应商的省心，换来的是要自己盯模型上下架

**换来的**：

- 月成本从约 15 元压到 1–3 元
- 换供应商/换模型的成本≈0（改一个环境变量）
- 无参考照时自动降到最便宜档，不浪费钱

## 何时重开

- **SiliconFlow 模型下架**（报错 `model 不存在`）→ 去官网 Models 页查当前可用名，改环境变量即可，不必改代码
- **图生图被拒**（内容审核）→ 换一个支持 I2I 的模型
- **出图质量不满意**且愿意加钱 → 切旧试穿模型（已终止，效果最好）
- **想彻底免 key** → 切 `hunyuan`，接受 5 倍成本
